# Three-jurisdiction testing model comparison

**Status:** experimental / incomplete  
**As of:** 2026-09-19

This document compares the narrow evidence currently encoded in the WeedDAO registry. It is not a complete legal comparison.

| Dimension | California seed | Oregon seed | Texas TCUP seed |
|---|---|---|---|
| Current registry focus | Pesticide action limits | Pesticide action limits | Required test categories + reporting + dosage-unit definition |
| Numeric analyte limits encoded | Yes | Yes | No per-analyte contaminant limits encoded from §12.7(b) |
| Product scope changes thresholds | Yes — inhalable vs non-inhalable | Not in current narrow seed | Current statute uses dosage-unit THC definition |
| Time-versioned rules | Phase I / Phase II | Active Table 3 seed | 2025 statute separated from older admin-rule text |
| Reporting requirements represented | Not yet | Not yet | Yes |
| Separate independent cannabis-lab model assumed | No assumption in registry | No assumption in registry | No — DPS says only licensed dispensing organizations may test TCUP products |
| Known source conflict / drift | None yet in narrow seed | 2026 proposals intentionally not encoded as active | Yes — current statute vs older §12.7(q) wording |

## Why this matters

The first three jurisdictions already show that a useful cannabis-testing rules layer cannot be modeled as one universal table of analyte limits.

A durable registry needs to support:

- stable analyte identity;
- jurisdiction;
- program;
- product scope;
- effective dates;
- required-test categories;
- numeric thresholds where they exist;
- reporting obligations;
- permitted testing actors;
- source conflicts;
- proposed vs active rules.

This is the direction WeedDAO should preserve as the registry grows.
