# Review evidence log — v0.2-draft

This file records **independent external** review and implementation evidence for WeedDAO Cannabis Data Record `v0.2-draft`.

No fabricated reviewers. Empty categories remain until real evidence is submitted and verified by maintainers.

WeedDAO-authored corpus mappings and examples are **not** external evidence.

---

## Milestone definitions (distinct)

| Milestone | Definition |
|-----------|------------|
| **FIRST_EXTERNAL_VALID_RECORD** | An independent party (not WeedDAO maintainers) produces a JSON document that validates against `schemas/weeddao-record-v0.2-draft.schema.json`. May be synthetic or redacted. WeedDAO must not author the record. |
| **FIRST_EXTERNAL_IMPLEMENTATION** | An independent party maps real operational data from their own system (grow software, LIMS, research DB, dispensary/product pipeline, etc.) into `v0.2-draft` and reports the mapping experience. WeedDAO must not author that record for this milestone. |

A valid record alone does **not** equal an implementation. An implementation implies real-system mapping work beyond copying an example.
