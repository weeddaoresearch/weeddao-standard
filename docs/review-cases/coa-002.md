## Purpose

This case tests whether WeedDAO Open Cannabis Data Standard **v0.1-alpha** can represent an actual medical concentrate Certificate of Analysis (COA) workflow for **interoperability review**.

WeedDAO is **not** independently verifying laboratory analytical results, accreditation, or product safety.

## What mapped cleanly

- Producer, license, batch ID, cultivar code
- Detected numeric cannabinoids and terpenes (%wt)
- Total THC %
- Microbial panel with organism-level `not_detected`
- Residual solvent PASS + limits
- Pesticide / heavy-metal **panel** pass status

## What could not be represented faithfully in core fields

- Explicit **ND** for cannabinoids and terpenes (must omit or falsely collapse)
- Heavy metal **`<0.008` ppm** per-analyte strings (issue #1)
- Simultaneous **% / mg/g / mg/unit** representations (dose interoperability)
- Best-by date and visual inspection as first-class fields
- Finished product display/SKU name
