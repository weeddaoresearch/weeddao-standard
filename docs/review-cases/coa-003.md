## Purpose

This case tests whether WeedDAO Open Cannabis Data Standard **v0.1-alpha** can represent an actual medical distillate syringe Certificate of Analysis (COA) workflow for **interoperability review**, including an **ambiguous literal batch ID `"0"`**.

WeedDAO is **not** independently verifying laboratory analytical results, accreditation, or product safety.

## What mapped cleanly

- Producer, license, cultivar code
- Literal batch ID `"0"` as string (core field accepts it)
- Detected CBN / THC / Total THC (%wt)
- Detected terpenes
- Microbial / residual solvent / pesticide panel semantics (same pattern as COA-002)

## What could not be represented faithfully in core fields

- Explicit **ND** for cannabinoids and terpenes
- Heavy metal **`<0.008` ppm**
- Concurrent **% / mg/g / mg/unit**
- Best-by and visual inspection first-class fields
- Semantic clarity that batch `"0"` might be placeholder vs intentional (documented in extensions; schema accepts the string)

## Batch ID `"0"` ambiguity

The certificate shows batch ID as the literal character `0`. This mapping **preserves** `cultivation_batch_id: "0"`. Converting to `null` would silently destroy the token and risk false merges with “missing batch” records. Whether `"0"` is intentional, a print artifact, or a placeholder is **unknown** — documented in `extensions.weeddao_review.batch_id_ambiguity_note`. This is IMPORTANT documentation, not automatically a CRITICAL schema defect (string field already holds the value).
