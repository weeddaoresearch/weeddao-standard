## Purpose

This case tests whether WeedDAO Open Cannabis Data Standard **v0.1-alpha** can represent an actual cultivation/laboratory Certificate of Analysis (COA) workflow for **interoperability review**.

WeedDAO is **not** independently verifying laboratory analytical results, accreditation, or product safety.

- Exact laboratory legal name (use `external-lab-001`)
- BioTrack / regulatory tracking identifiers
- Any claim that WeedDAO re-tested the sample
