# Request for Comments — WeedDAO Cannabis Data Record v0.2 Draft

**Draft:** `0.2-draft`  
**Date opened:** 2026-09-18  
**Status:** Open for independent external comment  
**Not:** a release tag, regulatory standard, certification scheme, or adoption claim

`v0.1-alpha` remains the published frozen baseline. This RFC covers the evidence-driven successor on branch `v0.2-draft`.

Branch: https://github.com/weeddaoresearch/weeddao-standard/tree/v0.2-draft

## Purpose

Invite growers, labs/LIMS practitioners, researchers, software developers, and dispensary/product-data operators to comment on whether `v0.2-draft` can represent real cannabis records without sentinel values or cultivation-batch-only assumptions.

## Focus

Prefer answers to the **10 questions** in [v0.2-external-review-brief.md](v0.2-external-review-brief.md), plus any mapping friction from real systems.

Do **not** treat WeedDAO-authored corpus shadow mappings as external implementation evidence.

## How to comment

- Open `.github/ISSUE_TEMPLATE/v0.2-implementation-feedback.md` (identity optional)
- Or file a schema/problem issue describing path, impact, and a concrete proposal
- Redacted JSON preferred; no PII

## Out of scope for this RFC

- Merging to `main`
- Creating a `v0.2` tag or GitHub release
- Changing frozen `v0.1-alpha` schema or tag
- Claiming industry adoption
