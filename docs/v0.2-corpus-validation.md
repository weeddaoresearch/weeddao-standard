# v0.2-draft corpus shadow validation

## Method

Deterministic mapper: `corpus/v0.2-draft/scripts/build_shadow_mappings.py`

**Inputs (read-only):** `corpus/v0.1/{cases,mappings,reviews,manifest.*}`  
**Outputs:** `corpus/v0.2-draft/{mappings,reviews,resolution_stats.json,build_stats.json}`

No PDFs, no web refetch, no rewrite of `corpus/v0.1`.

For each case:

1. Determine whether issues #1–#4 are relevant from v0.1 review gaps (and `uses_*` flags as fallback).
2. Map into v0.2-draft **core** so those semantics are not stranded in `weeddao_review` / `weeddao_corpus` workaround fields.
3. Set subject-semantics invalid if a finished product is still treated as `cultivation_batch` or a product name is still used as cultivar genetics.

## Resolution formula

```
CRITICAL_GAP_CORE_RESOLUTION_RATE =
  sum(ISSUE_N_RESOLVED_IN_CORE for N=1..4)
  / sum(ISSUE_N_RELEVANT_CASES for N=1..4)
```

`V0_2_DRAFT_READY=YES` requires rate **100%**.
