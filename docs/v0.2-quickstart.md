# Quickstart — WeedDAO Cannabis Data Record v0.2 Draft

**Standard:** WeedDAO Cannabis Data Record `v0.2-draft` (EXTERNAL REVIEW CANDIDATE)  
**Not:** a release, industry standard, regulatory specification, or adoption claim  
**Baseline still published:** `v0.1-alpha` (frozen)

Branch: https://github.com/weeddaoresearch/weeddao-standard/tree/v0.2-draft

## 1. Clone and checkout (~1 min)

```bash
git clone https://github.com/weeddaoresearch/weeddao-standard.git
cd weeddao-standard
git checkout v0.2-draft
```

## 2. Open the schema (~1 min)

```text
schemas/weeddao-record-v0.2-draft.schema.json
```

Dialect: JSON Schema Draft 2020-12. Instance documents must set `"schema_version": "0.2-draft"`.

Design notes: [v0.2-design.md](v0.2-design.md). Migration from v0.1: [v0.1-to-v0.2-migration.md](v0.1-to-v0.2-migration.md).

```json
    "subject_type": "sample",

```

## 4. Validate locally (~4 min)

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python scripts/validate_v0.2.py
python scripts/validate_v0.2.py path/to/your-record.json
```

Optional corpus shadow check (maintainers / advanced reviewers):

```bash
python scripts/validate_v0.2.py --shadow
```

v0.1-alpha remains separately validatable with `python scripts/validate.py`.

## 5. INDEPENDENT IMPLEMENTATION CHALLENGE

Goal: produce a structurally valid `0.2-draft` record from **your** data (or a carefully redacted real COA / LIMS export), without WeedDAO authoring it.

Steps:

1. Copy any file under `examples/v0.2-draft/` as a starting point.
2. Replace identifiers, subject, and lab sections with **your own** or **redacted** data. Do not paste PII.
3. Encode ND / `<LOQ` / NOT_PERFORMED with `result_state` — do **not** use numeric `0` as a sentinel for missing or non-detected values.
4. Validate: `python scripts/validate_v0.2.py your-record.json`
5. Report via `.github/ISSUE_TEMPLATE/v0.2-implementation-feedback.md` (identity optional), or note results in your own tracker.

### Milestone definitions (distinct)

| Milestone | Meaning |
|-----------|---------|
| **FIRST_EXTERNAL_VALID_RECORD** | An independent party produces a record that validates against `v0.2-draft` (may be synthetic/redacted). WeedDAO did not author the JSON. |
| **FIRST_EXTERNAL_IMPLEMENTATION** | An independent party maps real operational data (grow software, LIMS, research DB, dispensary/product system) into `v0.2-draft` and reports mapping experience. WeedDAO must **not** author that record for the milestone. |

WeedDAO maintainers mapping COAs for corpus evidence does **not** count as either milestone.
